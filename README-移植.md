# 移植到其他电脑

## 能直接搬过去吗

**能，但要把整个文件夹一起搬**，不能只复制 `.py` 文件。

已经打包成绿色版：目录里的 `python\` 自带解释器和依赖（numpy、Pillow），
目标电脑**不需要安装 Python**，也不需要装 DeepSeek Harness。

整个 `game-bot` 文件夹约 **157 MB**。

## 目标电脑需要什么

| 条件 | 说明 |
|---|---|
| 系统 | Windows 10 / 11（脚本用 Win32 API，不支持 macOS） |
| 微信 | PC 版微信，打开「动物餐厅」小程序 |
| 权限 | 普通用户即可，不需要管理员 |
| 网络 | 不需要 |

## 三步

1. 把整个 `game-bot` 文件夹拷到目标电脑任意位置（路径别太深、别放只读目录）
2. 打开微信，进入「动物餐厅」小程序，**窗口别最小化**
3. 双击 `start-daemon.bat`

第一次建议先双击 `dry-run.bat`，它只识别不点击，跑 30 秒看看输出：

```
[10:00:01] #0001 unknown      score=0.0
```

如果一直是 `unknown` 且 `发现 0 个掉落物`，说明识别没生效，往下看“需要重新校准”那节。

## 移植后的注意事项

### 1. 窗口不能被遮挡

截图走的是屏幕抓取（这个游戏窗口开了硬件加速，专用截图接口是黑屏）。
所以只要游戏窗口被浏览器、聊天窗口盖住，脚本截到的就是盖住它的那个窗口，
点击也会点到上面去。**运行期间把游戏窗口放在最前面。**

### 2. 分辨率、缩放可以不同

截图会统一归一化到 415×790 再识别，点击按实际窗口大小换算，
所以目标电脑分辨率不同、窗口拉大拉小都不影响。

### 3. 需要重新校准的情况

模板图（`templates\*.png`）是在这台机器上截的。绝大多数 Windows 电脑渲染一致，
可以直接用。但以下情况分数会下降，需要重新截模板：

- 系统缩放比例差异极大（比如 100% 对 200%）导致画面被拉伸
- 游戏 UI 版本更新（按钮位置、配色变了）

判断方法：`dry-run.bat` 里如果「识别到弹框」或「发现掉落物」长期为 0，就是需要重截。
重截流程很简单：把画面截图发我，我重新切模板。

### 4. 锁屏

锁屏后脚本无法操作游戏，这是 Windows 的限制。脚本已经内置：
- 阻止显示器休眠和系统睡眠
- 每 240 秒微动一次光标，避免被“10 分钟空闲锁屏”策略锁掉

目标电脑如果锁屏策略更激进（比如 5 分钟），在 `daemon.py` 启动参数里调小：

```
--keepalive 120
```

### 5. 杀毒软件

脚本会启动自带的 `python.exe` 并模拟鼠标点击，个别杀毒软件会拦。
出现拦截提示时选择允许即可。

## 想减小体积？

删掉 `python\` 文件夹（省约 150 MB），然后在那台电脑上装 Python 3.10+：

```
pip install numpy pillow
```

`_python.bat` 会自动依次查找：`.\python\python.exe` → `DSH_HOME` 下的运行时 → 系统 PATH 里的 python。

## 文件清单（哪些必须带）

| 必须 | 说明 |
|---|---|

| `*.bat` | 入口脚本 |
